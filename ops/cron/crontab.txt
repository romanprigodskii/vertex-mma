# Vertex MMA data pipeline (wrappers in /opt/vertex-cron/*.sh)
# All scrapers share /var/lock/vertex-scrape.lock so they never overlap.
# git pull is best-effort: a fetch failure leaves the checkout pinned,
# it never aborts a job.

# Hourly — news pipeline (RSS -> classify -> rephrase -> translate)
0 * * * *    /opt/vertex-cron/news-refresh.sh

# Every 6h — light: re-list events + recent bouts (results) + odds + matview
0 */6 * * *  /opt/vertex-cron/scrape-refresh.sh

# Every 6h at :20 — diff our upcoming cards against the live UFCStats cards,
# 20 min after the refresh above so it checks what that scrape just wrote.
# Read-only. Logs `CARD DRIFT` when a bout is on one side and not the other.
20 */6 * * * /opt/vertex-cron/verify-cards.sh

# The three jobs below moved 30 min earlier on 2026-09-04. Order and the 30 min
# gaps between them are unchanged; what changed is the room left for the
# recompute chain, which now also rebuilds the fighter_vertex_score matview
# (Wave 62). That refresh measured 2,315 s on the starved instance the incident
# left behind — the chain itself only takes ~6.5 min, so at 04:30 it would have
# run past predict at 05:15 and predict would have scored on yesterday's
# ratings. Starting at 04:00 gives the chain 75 min instead of 45. The refresh
# cost falls as the instance recovers; the headroom is what makes that
# irrelevant either way.

# Daily 03:00 — live ufc.com/rankings -> ranking_snapshot, before the daily
# recompute so fresh ranks land in scores the same day
0 3 * * *    /opt/vertex-cron/rankings-refresh.sh

# Daily 03:30 — Sherdog pre-UFC histories for new + upcoming-bout fighters,
# before predict 05:15 so debutant records reach the model the same morning
30 3 * * *   /opt/vertex-cron/sherdog-refresh.sh

# Daily 04:00 — per-round bout stats + judge scorecards + full recompute
0 4 * * *    /opt/vertex-cron/scrape-stats.sh

# Daily 05:15 — score upcoming bouts with the model (winner + Monte-Carlo
# props) AFTER the stats+recompute so predictions use fresh features. Keeps
# bout_simulation + sportsbook prop markets from going stale.
15 5 * * *   /opt/vertex-cron/predict-refresh.sh

# Weekly Sun 05:30 — full A-Z scrape (incl. enrich-fighters) + recompute
30 5 * * 0   /opt/vertex-cron/scrape-full.sh

# Weekly Sun 07:00 — retrain the model on the latest data (refit-on-all) and
# push refreshed artifacts if the weights changed, AFTER the full scrape +
# recompute. Keeps the served weights from drifting (no-op when no new fights).
0 7 * * 0    /opt/vertex-cron/retrain-refresh.sh

# Daily 02:00 — back up the self-hosted Postgres (Supabase used to do this)
0 2 * * *    /opt/vertex-cron/db-backup.sh
